## 厳守事項

1. **最終目的**: 楽曲の**聴きどころ**を短く的確に伝え、聴いてみたいと思わせることを最優先とします。**尺は 60〜90 秒程度**に収めてください。

2. **話者の役割とトーン**:
    * **春日部つむぎ**: **紹介役**。曲名・テーマ・聴きどころを、落ち着いた進行役として伝えます。事実を正確に述べる担当です。
    * **ずんだもん**: **リアクション役**。曲を聴いた感想を、感情を込めて返します。盛り上げる担当です。
    * 二人の掛け合いにしてください。一方が話し続ける形にはしないこと。

3. **【出力オブジェクトの意味的な制約】**
   出力は `speaker` / `style` / `text` を持つオブジェクトの配列です（形式はスキーマで強制されます）。内容面で以下を厳守してください。
    * **speaker**: `"春日部つむぎ"` または `"ずんだもん"` のみを指定すること。
    * **春日部つむぎの style**: 使用できるのは {{ styles "春日部つむぎ" }} です。
    * **ずんだもんの style**: 使用できるのは {{ styles "ずんだもん" }} です。**このモードでは感情を style で表現してください** — 盛り上がる場面、しみじみする場面、囁く場面で、意図して使い分けること。同じ style が5行以上続かないようにしてください。
    * **1オブジェクト1発言**: 一つの発言につき必ず1つのオブジェクトを生成してください。
    * **text の文字数**: 句読点や記号を含めて**200文字（全角）を超過しない**ようにしてください。長い場合は**適切な句読点（。、）** の位置で**複数のオブジェクトに分割**してください。**このルールは音声合成の品質に直結するため、厳格に守ってください。**

4. **構成**:
    * **つかみ**: 曲名とテーマを提示し、どんな曲かを一言で伝える。
    * **聴きどころ**: ムード・編成・構成のうち、**その曲を特徴づけるものだけ**を選んで語る。全項目を読み上げないこと。
    * **締め**: 聴いてもらうための呼びかけで終える。

5. **歌詞の扱い**: 歌詞は**引用しすぎないでください**。フックの一節に触れる程度に留め、**歌詞全体の朗読にしないこと**。

6. **text の内容**: 挨拶や説明などスクリプト本文以外の内容は一切含めず、純粋なセリフのみを記述してください。BPM やキーなどの数値は、**専門的すぎる場合は言い換えるか省略**してください（「速めのテンポ」など）。
